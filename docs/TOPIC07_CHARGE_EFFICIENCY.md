# 课题07：充电宝/充电器标称容量与转换效率核验

> 目标：拿一个充电宝（当前样机：华为 CP11QC），用 USB 电压电流检测仪测它从满电放到自动关机的完整输出曲线，
> 计算“标称能量 → 实际输出 → 手机电池实际获得”的三段效率，并解释升压/线损/充电损耗的去向。

## 1. 铭牌与关键数字

| 项目 | 铭牌值 | 说明 |
|---|---|---|
| 型号 | Huawei CP11QC | 华为快充移动电源 |
| 电池容量 | 10000 mAh 典型 / 9500 mAh 额定 | 电芯容量（3.7V 级） |
| 额定容量 | 6200 mAh (5V/2A) | 输出侧可交付容量 |
| 锂离子电池额定能量 | 34.49 Wh | 效率分母用这个 |
| 输入/输出 | 5V/9V = 2A (Max) | 支持快充 |
| 电芯标称电压 | 3.85 V（按常见锂电） | 仅用于换算 |

**先算清楚三件事：**

1. 额定输出能量 = 6200 mAh × 5 V = **31.0 Wh**；
2. 铭牌反推的升压转换效率 = 31.0 / 34.49 ≈ **89.9%**（电芯 3.7V → 5V 的升压+转换）；
3. 不要拿“10000 mAh”直接和手机充入的 mAh 比：电压平台不同，必须用 Wh。

## 2. 实验方法

### 2.1 器材与准备

- 充电宝（CP11QC）充满：指示灯全亮后再充 30 min；
- USB 电压电流检测仪串在**充电宝输出口与手机之间**，记录电压 V、电流 A（有累计 Wh 功能就一并记录）；
- 手机固定起始电量：**20% ± 2%**（每次实验尽量一致，便于对比）；
- 手机屏幕熄灭、关闭 Wi-Fi/蓝牙/移动数据/热点，环境温度 20–28°C；
- 记录起始时间、环境温度、测试仪型号/精度、手机型号。

### 2.2 记录流程

1. 接好后先记第 0 行（t=0，此刻电压/电流/手机电量）；
2. **每 10 min 记录一行**：USB 电压、电流、手机电量百分比；有电荷计读数的手机可填 µAh（可留空）；
3. 手机充满后不要停：继续记录，直到**充电宝自动关机 / 手机停止充电**；
4. 最后一行写“结束：充电宝自动关机”；
5. 至少重复 **2 次**完整放电（条件一致），报告给均值与极差。

> 提醒：10 min 采样是交付要求；中途漏 1–2 行可在 note 说明，不要伪造。

### 2.3 数据表字段

| 字段 | 含义 | 单位 |
|---|---|---|
| point_index | 行号（0 开始） | — |
| elapsed_min | 相对开始时间 | min |
| timestamp_iso | 绝对时间（带时区） | ISO8601 |
| usb_voltage_v | 检测仪电压 | V |

| phone_battery_temp_c | 手机电池温度 | °C |

## 3. 计算口径

设第 i 个采样点输出功率 P_i = V_i × I_i，Δt_i 为相邻点时间间隔（h）。

1. **充电宝输出能量**：E_out = Σ (P_i + P_i+1)/2 × Δt_i（梯形积分）；
2. **手机电池获得能量**：
   - 有电荷计：E_phone = (Q_start − Q_end) µAh × V_phone(mV) / 1e9（Wh）；
   - 没有电荷计：E_phone = Δ电量% / 100 × 手机电池容量(mAh)/1000 × 标称电压(V)；
3. **三段效率**：
   - η_output = E_out / 34.49（电芯 → 输出，含升压/转换）；
   - η_charge = E_phone / E_out（线缆 + 手机内部充电管理）；
   - η_total = E_phone / 34.49（电芯 → 手机电池，整体）；
4. **等效输出容量** = E_out / 5V × 1000（mAh），和 6200 mAh 比；
5. **损耗分解**：
   - 升压/转换损耗 = 34.49 − E_out；
   - 线损 + 手机充电损耗 = E_out − E_phone。

## 5. 预期值与损耗去向（写报告参考）

| 指标 | 合理范围（CP11QC 级别） |
|---|---|
| E_out（输出能量） | 27–31 Wh（对应 η_output 78–90%） |
| E_phone（手机获得） | 20–26 Wh（取决于手机充电效率与起始电量） |
| η_charge（手机/输出） | 75–90% |
| η_total（手机/标称） | 60–78% |
| 升压损耗占比 | 约 10–15% |
| 线缆 + 手机充电损耗占比 | 约 10–25% |

损耗去向要分开写：
1. **升压转换**：电芯 3.7V → 5V/9V，开关电源效率一般 85–93%，其余变热；
2. **线缆/接口**：I²R 与接触电阻，1–2A 时约 0.5–2 W；
3. **手机内部充电管理**：降压/线性充电、屏幕与系统耗电、发热；
4. **充电宝自身待机/指示/保护电路**：长时间放电时的固定功耗。

## 6. 常见坑

- 手机亮屏/开热点会让“手机获得能量”偏小，效率算低；
- 起始电量不一致，充电曲线不同（20% 与 80% 的充电效率差别大）；
- 检测仪本身有压降/功耗，尽量用低内阻的表；
- 充电宝标注 10000 mAh 是电芯容量，不是输出容量；
- 只测到手机 100% 就停，会漏掉“手机满后充电宝剩余能量”的去向；要继续到充电宝关机；
- 温度过低/过高都会改变效率，报告要写环境温度。
