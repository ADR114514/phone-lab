## 摘要

本文用 USB 电压电流检测仪记录充电宝从满电到自动关机的完整输出曲线（每 10 min 一行），
计算电芯标称能量 → 输出能量 → 手机电池获得能量的三段转换效率，并分解升压、线缆与手机充电损耗。
该充电宝铭牌额定能量 34.49 Wh、额定输出容量 6200 mAh(5V/2A)；实测输出能量 ____ Wh（η_output ____%），
手机电池获得 ____ Wh（η_charge ____%），整体效率 ____%。损耗主要来自 ____（约 ____%），
其次为 ____（约 ____%）。与铭牌反推的升压效率 89.9% 相比，差异主要解释为 ____。

**关键词**：充电宝；转换效率；升压损耗；能量核验；USB 功率计

## 1. 实验目的

1. 核验充电宝铭牌能量/容量是否可复现；
2. 量化“电芯 → 5V 输出 → 手机电池”三段效率；
3. 分解升压、线缆、手机充电管理的损耗去向；
4. 给出可重复的测量方法与误差来源。

## 2. 实验对象与方法

### 2.1 充电宝铭牌

| 项目 | 值 |
|---|---|
| 型号 | 华为 CP11QC |
| 电池容量 | 10000 mAh（典型）/ 9500 mAh（额定） |
| 额定容量 | 6200 mAh (5V/2A) |
| 额定能量 | 34.49 Wh |
| 输入 / 输出 | 5V/9V = 2A (Max) |
| 电芯电压（换算用） | 3.85 V |

铭牌反推升压效率 = 6200 mAh × 5 V / 34.49 Wh = 31.0 Wh / 34.49 Wh ≈ 89.9%。

### 2.2 测量装置

- USB 检测仪串接在充电宝输出与手机之间，记录电压 V、电流 A；
- 手机（____）起始电量固定 ____%，屏幕熄灭，关闭 Wi-Fi/蓝牙/移动数据；
- 环境温度 ____ °C，测试仪型号 ____，电压/电流分辨率 ____；
- 每隔 10 min 记录一行，直到充电宝自动关机；共 ____ 行，时长 ____ h。

### 2.3 数据口径

| 量 | 定义 | 公式 |
|---|---|---|
| 输出功率 | 检测仪瞬时功率 | P = V × I |
| 输出能量 | 梯形积分 | E_out = Σ (P_i + P_i+1)/2 × Δt |
| 手机获得能量 | 电荷计差分（优先） | E_phone = ΔQ(µAh) × V_bat(mV) / 1e9 |
| 手机获得能量（近似） | 电量百分比 × 容量 | E_phone = Δ% /100 × C(mAh)/1000 × V_nom |
| 输出效率 | 电芯 → 输出 | η_output = E_out / 34.49 |
| 充电效率 | 输出 → 手机电池 | η_charge = E_phone / E_out |
| 整体效率 | 电芯 → 手机电池 | η_total = E_phone / 34.49 |

### 2.4 误差来源

1. 检测仪精度与内阻压降；
2. 10 min 采样对功率变化的平滑（漏掉峰值/末段跌落）；
3. 手机电量百分比 1% 量化、电池容量标称值误差；
4. 手机亮屏/后台活动带来的额外耗电；
5. 起始电量、温度、线缆不同导致的效率差异。

## 4. 讨论

5. **重复性**：两次实验 η_total 分别为 ____% / ____%，极差 ____%，主要来自 ____。

## 5. 局限与改进

- 10 min 采样无法捕捉瞬时峰值；可用带记录功能的功率计以 1 s 采样复核；
- 手机电量百分比只有 1% 分辨率，建议同时记录电荷计 µAh；
- 仅测一台充电宝/一根线，结论不外推到所有产品；
- 温度与起始电量未做多水平控制，可设计 2×2 实验进一步分析。
