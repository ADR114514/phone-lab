# 课题 07 · 充电宝／充电器标称容量与转换效率核验

**华为 CP11QC · 会话 CA-20261123_144032 · App 记录版。** 本批记录给手机从 **19% 充至 96%** 的过程。新版导出已保存用户补记的「充电宝耗尽」，但最后一条仪表采样仍有输出，未记录停机末点。数据、曲线和阶段性结论可用，不能将它们当作完整放电容量或整程效率。

**本批结果：**第 14 点 App 原值 **10.7 A** 超出铭牌 **2 A**，保留并标注；只排除它前后两个区间，不填值、不跨空档。其余 **16 个区间、共 174.97 分钟**估算输出 **33.13 Wh**，不是整程转换效率。App 原汇总 **50.675 Wh** 含超限点，仅作原始证据。

**新版导出核对：**[结束状态](follow-up-export/manifest.json) · [新版能量汇总](follow-up-export/summary.json)。原始 19 条 CSV 与旧导出逐字节一致，因此不重复存放。2026-11-24 01:43:36（北京时间）是补记时间，不是实测停机时间。

**现场照已归档。** 两张照片展示同一会话的充电宝、USB 表和 App 界面。界面仍显示「正在充电」及「保存第 20 点」，对应的第 20 条记录未出现在导出的 19 点 CSV 中。照片上的输入框数值不用于替换已保存的 App 数据。

**仍无法从现有材料核算：**整程输出／铭牌比缺少停机末段读数；USB 往返效率还需要独立的充电宝输入侧原始记录。编号 2002–2011 的仪表照片所示读数与已有放电前段吻合，未作为独立输入侧测量。[输入侧记录空表](输入侧记录空表.csv)可用于单独记录输入数据。

## 复现

在本目录，用 Python 3.11+ 和 Matplotlib 执行：

~~~sh
python -m pip install matplotlib
python analyze_app.py
~~~

脚本核对原件哈希，只读取 App 导出，生成中文表、保留区间和曲线。接线照仅作布置证据，不参与能量计算。
